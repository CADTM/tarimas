# Calculadora de Tarimas

Calculadora con control de cajas paletizadas por tarima: número de parte, batch (se puede escanear), cajas, piezas, Destino, Delivery y HU. Agrupa por destino y delivery, permite cerrarlos y genera PDF (resumen gráfico en carta + tickets por tarima, o rollo térmico 80/58 mm).

- En línea: https://tarimas.cybercadtm.com/
- Se instala como app (Android/Chrome: botón **Instalar app**; iPhone: Compartir → Agregar a pantalla de inicio) y funciona sin internet una vez abierta.
- Los datos se guardan en el navegador del dispositivo (no se suben a ningún servidor).
